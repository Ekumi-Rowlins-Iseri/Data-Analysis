 # Data Analysis Project

## Overview
This project involves cleaning and analyzing a dataset using Microsoft Excel to identify messy data and compare the bias in the admission process. The goal was to transform raw, messy data into a clean, structured format and extract meaningful insights.

## Objectives
- Clean and prepare raw data for analysis
- Identify redundancy and duplication/inconsistency 
- Present findings through clear visualizations and summaries

## Tools Used
- Microsoft Excel
- Conditional Formatting with COUNTIF AND COUNTIFS,COUNTBLANK, / Charts — list whichever features you actually used

## Process
1. **Data Cleaning**: The same rows, with three new formula-driven columns (Major (Clean), Gender (Clean), Admission (Clean)) that standardize every typo into a consistent category, live — built with Excel formulas, not hardcoded values.
2. **Data Exploration**: Reviewed the dataset structure and identified key variables/Documents exactly what was dirty in the source file and the rule used to fix each field, so the cleaning is auditable rather than a black box.
3. **Analysis**: COUNTIFS-based pivot-style tables: overall acceptance rate by gender, and acceptance rate by gender WITHIN each major — plus the two charts that make the explanation visible.
4. **Visualization**: Created charts/graphs to represent aggregate and disaggregate paradox

## Key Findings
- Overall acceptance rate, by gender (all majors combined)
- Acceptance rate by major, split by gender
- Identify if the admission data is bias over Male or or Female
